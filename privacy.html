Privacy Policy

Personal OS — Mail Sync · last updated 30 September 2026

Summary

This application is used by one person, on their own accounts, to file their own email into their own private notes. No other person's data is processed, and no data leaves the owner's control.

What is accessed

  • Message content, senders, recipients, subjects and dates from Gmail accounts the owner has personally authorised.
  • Scope requested: gmail.readonly — read-only. The application cannot send, delete, modify or label mail.

How it is used

Messages are converted to text notes and stored in a private repository the owner controls, so they can be searched alongside the owner's other personal records. That is the only use.

Sharing

None. Data is not sold, rented, shared with third parties, used for advertising, or used to train any machine-learning model.

Storage and retention

Notes are stored in the owner's own private repository and on the owner's own server. They are retained for as long as the owner keeps them and can be deleted by the owner at any time.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke this application's access at any time at myaccount.google.com/permissions, which immediately stops all further access.
